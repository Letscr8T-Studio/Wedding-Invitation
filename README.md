# Mary & Emmanuel — Wedding Website (starter kit)

## How to start
1. Create a folder on your Desktop, e.g. `mary-emmanuel-wedding`.
2. Unzip this kit **into** that folder, so `CLAUDE.md` sits at the top level.
3. Open the folder in VS Code (File → Open Folder).
4. Open the Claude panel and paste the message from `START_PROMPT.md`.
5. Go phase by phase. Say **"next"** when you're happy with each one.

## What's inside
| File | What it is |
|---|---|
| `CLAUDE.md` | Rules Claude reads automatically on every message |
| `START_PROMPT.md` | Your first message, plus follow-up prompts |
| `docs/DESIGN_SPEC.md` | The full design system and section spec |
| `docs/CONTENT.md` | All the wedding info. Edit it here when the couple sends details |
| `docs/BUILD_PLAN.md` | Phases 0–8: setup to deploy |
| `docs/RSVP_SETUP.md` | Free RSVP → Google Sheet setup |
| `design-reference/` | The approved designs (site, envelope intro, invite card) |
